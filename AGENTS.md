# Agent instructions

- Google Python style, line length 100, black. Type-annotate every function.
- **Parity is the definition of correct.** Goldens in `tests/golden/` are only
  regenerated by `pixi run -e reference golden`, in a commit that says why.
  The goldens include three summer3 bugs. Copy them on this branch; do not
  "fix" them here. `reference/summer3-bugs.md` lists each one, the edges it
  affects, and what the release model should do instead.
- **Glue is temporary and labelled.** Every hand-written stand-in for a summer4
  gap carries a comment `# GLUE(TMn): replaced by WPk`. M3 is done when
  `grep -rn "GLUE(" src notebooks` is empty.
- Notebooks are a user gate: each phase PR lists the notebooks to run and the
  claim to check.
- Plans are immutable records in `plans/`.
- JAX float64 is enabled in `tb_macro/__init__.py`. The summer3 reference uses
  float64; summer4 does not turn it on.

```bash
pixi run test
pixi run format-check
pixi run -e reference golden   # only when regenerating goldens
```

Do not format `reference/snapshot/`. It is a read-only vendored tree.
