# Agent instructions

- Google Python style, line length 100, black. Type-annotate every function.
- **Default is the corrected model.** `run(params)` and `compile_model()` send
  replacement deaths to age 0, let the progression split sum to one, put
  `rel_infectiousness_subclin` on subclinical disease, use the folded spline
  contact matrix, and use the smooth entry rate. Goldens in `tests/golden/`
  still record the three summer3 bugs plus year-frozen mixing and step entry;
  parity tests pass `match_golden=True`. Goldens are only regenerated by
  `pixi run -e reference golden`, in a commit that says why.
  `reference/summer3-bugs.md` lists each bug, the edges it affects, and what
  the default model does instead.
- **Glue is temporary and labelled.** Every hand-written stand-in for a summer4
  gap carries a comment `# GLUE(TMn): replaced by WPk`. M3 is done when
  `grep -rn "GLUE(" src notebooks` is empty.
- Notebooks are a user gate: each phase PR lists the notebooks to run and the
  claim to check.
- Plans are immutable records in `plans/`.
- JAX float64 is enabled in `tb_macro/__init__.py`. The summer3 reference uses
  float64; summer4 does not turn it on.

```bash
pixi run test
pixi run format-check
pixi run -e reference golden   # only when regenerating goldens
```

Do not format `reference/snapshot/`. It is a read-only vendored tree.
